# Outfitler

## Projektbeskrivning

Outfitler är en web app för att skapa översikt över alla sina klädesplagg och hur de kan kombineras ihop till outfits. Användaren kan ge varje klädesplagg och outfit taggar, ratings mm för att kunna filtrera med mm.

## Projektplan

Läs alltid in `plan/outfitler_overview.md` i sin helhet i varje konversation, oavsett vad uppgiften gäller. Planen beskriver datamodellen (plagg, outfits, taggar, ratings), huvudfunktioner, bildhantering, UI-vyer, färgpalett och teknisk plattform. Alla förslag och lösningar ska följa de principer och beslut som dokumenterats där.

## Teknisk stack

- **Frontend:** Web app – HTML/CSS/Vanilla JS (byggd på auth-templaten `webapp-with-auth-template`)
- **Backend:** Node.js / Express
- **Databas:** PostgreSQL (Railway.app)
- **Bildlagring:** ej fastställd (definieras i planen)
- **Autentisering:** JWT + Google OAuth (redan implementerat)
- **Hosting:** Railway.app
